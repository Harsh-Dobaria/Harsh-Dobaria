## 🚀 Featured Projects

### 🧠 ContextAI
**Multi-Agent RAG Platform**

A modular RAG platform built around multi-agent orchestration and hybrid retrieval.

**Tech:** Python, FastAPI, React, LangGraph, LangChain, FAISS, BM25, Gemini, LangSmith

- Improved **Recall@5 from 60% → 66%** using FAISS + BM25 + Reciprocal Rank Fusion.
- Increased **Recall@5 from 66% → 84%** using Cross-Encoder reranking.
- Achieved **10.7 ms average latency** and **12.9 ms P95 latency** for search and fusion.
- Implemented conversational short-term memory and modular retrieval pipelines.

### 🤖 StartupAI
**AI-Powered Startup Incubation Platform**

A multi-role platform combining AI-based funding prediction with startup networking and investment workflows.

**Tech:** React.js, Django REST Framework, MongoDB, JWT, OTP, Render, Vercel

- Delivered **45+ REST APIs** for a 3-role platform.
- Improved funding-readiness **ROC-AUC from 0.79 → 0.84** using Random Forest.
- Built messaging, connection requests, payments, investment tracking, PDF generation, and email automation.
- Deployed using Render and Vercel.

---

### 🏏 CricPredict
**Explainable Cricket Win Probability Predictor**

An ML system for predicting real-time IPL match win probability.

**Tech:** Python, XGBoost, Pandas, NumPy, Scikit-learn, SHAP, Streamlit

- Trained an XGBoost classifier on **278K+ IPL ball-by-ball records**.
- Achieved **0.88 ROC-AUC** using 15 engineered match-state and contextual features.
- Engineered features including CRR, RRR, pressure, wickets/balls remaining, recent form, and player statistics.
- Integrated **SHAP TreeExplainer** for feature-level explanations.
- Deployed an interactive Streamlit application for real-time inference.
